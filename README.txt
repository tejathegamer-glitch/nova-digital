# NOVA DIGITAL — Free Starter Website

A responsive digital-products storefront built with plain HTML, CSS and JavaScript.

## Run on Windows for free

1. Download and extract `nova-digital.zip`.
2. Open the extracted `nova_digital` folder.
3. Double-click `index.html`. It opens in your browser.
4. Edit files using Notepad or a free editor such as Visual Studio Code.
5. Refresh the browser to see your changes.

No Node.js, build tools, or paid software are required.

## Publish free with GitHub Pages

1. Create a free account at https://github.com/
2. Create a new **public** repository, for example `nova-digital`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. Open **Settings → Pages**.
5. Under build and deployment, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for the published URL shown in Pages settings.

GitHub Pages is for static websites. The cart and search in this starter are browser-side demo features. The checkout button does not take payments; there is no customer account, order database, or secure digital file delivery yet. Never put secret API keys or private download files in this public repository.

## Customize products

Open `script.js` and edit the `products` array near the top. Each product has an id, name, category, price, description, icon, tag, background colors and type.

Categories: `ebooks`, `templates`, `courses`, `design`.

This starter uses sample product names and prices. Replace them with products you own or are authorized to sell before launch.
